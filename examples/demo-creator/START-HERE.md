# Start here

This folder contains your verified Creator Brain.

## First use

Open or attach this folder in a compatible AI environment and ask:

```text
Lee mi Creator Brain y explícame brevemente cómo debes crear contenido conmigo.
```

## Core files

- `CREATOR-CONTEXT.md`: concise universal profile.
- `CREATOR-GUIDE.md`: operating and update rules.
- `modules/`: detailed positioning, audience, offer, voice, strategy and knowledge projections.
- `.creator-brain/`: structured profile, provenance, coverage, calibration and verification.

Runtime files are adapters. The profile remains portable even when an environment does not automatically detect them.
