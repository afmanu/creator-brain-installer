# Schema review checklist

Before building the installer, confirm:

- The universal fields describe every individual creator profile.
- Each critical field truly requires explicit confirmation.
- Commercial, multi-channel and team fields activate only when relevant.
- No field belongs to editorial operations, scheduling or publishing.
- Every field can be answered by direct input, approved evidence or calibration.
- The schema captures public/private and claim boundaries.
- Voice includes both positive and negative examples.
- Completion can be computed without subjective guesswork.

Current catalog totals are produced by `npm run validate`.
