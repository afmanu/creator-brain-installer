# Installation experience

The target onboarding contains six planned user responses after the minimal installation request.

## Interaction 1 — Existing context and scope

Ask for accessible LLM context, files, folders or systems that may already describe the creator. Bundle source scope, exclusions, creator purpose, destination and initial state-write consent.

Example: `Utiliza el contexto de este proyecto y revisa C:\Creator. Incluye Perfil, Guiones y Publicaciones; excluye Clientes, Finanzas y conversaciones privadas. Quiero crear contenido sobre IA aplicada para LinkedIn y vídeo. Instala en C:\my-creator-brain y autorizo el estado inicial.`

## Interaction 2 — Additional sources

After inventory and extraction, request all remaining useful sources and only the initial facts that approved context could not supply.

Example: `Añade mi web, LinkedIn, cinco guiones, tres publicaciones aprobadas y dos ejemplos que no representan mi voz. Mi web define la oferta actual; el CV solo sirve para trayectoria.`

## Interaction 3 — Gaps and conflicts

Present one complete closure package: missing applicable fields, critical contradictions, stale claims, inaccessible evidence and inferences requiring confirmation.

Example: `Confirma si tu audiencia principal son fundadores no técnicos, cuál es tu promesa central y si el tono de LinkedIn también debe aplicarse a vídeo. El documento de posicionamiento contradice la web en la oferta actual.`

## Interaction 4 — Creator model

Present the complete proposed identity, positioning, audience, voice, strategy, knowledge boundaries and creative contract. Ask only for corrections.

Example: `Confirmo todo salvo que mi tono no es provocador; es directo. La audiencia secundaria debe ser equipos de innovación, no agencias.`

## Interaction 5 — Calibration

Run representative content decisions and generation tests. Resolve behavioral uncertainty through explicit choices and approved or rejected outputs.

Example: `Prefiero el hook B porque comienza con una observación propia. Mantén la versión corta, elimina la exageración y conserva la conclusión práctica.`

## Interaction 6 — Final approval

Show the complete output preview, source summary, coverage, calibration results, destination and files. Build only after explicit approval.

Example: `Cambia el CTA por una invitación a responder y aprueba después de aplicar ese cambio.`

Recovery messages caused by unavailable tools, invalid paths or missing permissions do not create new profile modules. They must be recorded as recovery within the current state and must not be disguised as successful onboarding progress.
