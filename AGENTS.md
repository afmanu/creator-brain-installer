# Creator Brain Installer

This repository is currently in the foundation phase.

When developing it:

- preserve the product boundary in `docs/product-contract.md`;
- treat `specs/profile-fields.json` as the finite completion denominator;
- update validation whenever the schema changes;
- keep the runtime core vendor-neutral;
- do not add operational Content OS features;
- do not claim link-only installation is ready until blind tests pass.

If a user asks to install the product before `BOOTSTRAP.md` exists, explain that the installer is not ready rather than simulating a successful installation.
