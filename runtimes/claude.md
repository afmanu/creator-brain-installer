# Claude runtime

Use actual local folder, command and web capabilities rather than assuming them from the Claude surface.

- Treat repository `CLAUDE.md` as the entry adapter.
- Read `BOOTSTRAP.md` before onboarding.
- Claude Code or a desktop environment with folder access may use full mode.
- A web or mobile conversation without local writes uses assisted or manual mode.
- The generated installed `CLAUDE.md` routes future work to the universal core.
- Do not present a handoff as a completed local installation.
