# Codex runtime

Use actual tool availability rather than assuming the environment from the product name.

- Treat repository `AGENTS.md` as the entry adapter.
- Read `BOOTSTRAP.md` before onboarding.
- Inspect local capabilities read-only before requesting writes.
- Use scoped filesystem permissions and preserve unrelated user changes.
- Use the generated installed `AGENTS.md` to route future work to `CREATOR-CONTEXT.md` and `CREATOR-GUIDE.md`.
- If the repository is available only by URL and cannot be cloned or read, use the generic blocked handoff.
